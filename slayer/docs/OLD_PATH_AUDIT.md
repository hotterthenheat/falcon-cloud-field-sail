# What is still on the old path — the audit (2026-11-07)

The Map and every exposure view read the two-book engine (`docs/TWO_BOOK_SPEC_V2.md`, built: `docs/TWO_BOOK.md`). The
Map-integration work left some parts on the old path, each with a reason. This file takes each one: what the code does,
whether there is a better way inside the spec and the data rules (`docs/DATA_SOURCES.md`), and what was done.

The proof for every behaviour change is `scripts/old-path-proof.ts` (in CI, `scripts/run-proofs.mjs`), on the recorded
SPY and SPX books in `scripts/fixtures/twobook/`. The engine's math is unchanged: `twobook-proof`,
`twobook-mutation-proof`, `twobook-server-proof`, `twobook-map-proof` and every golden pass as before.

## Task A (the Map's dead strip), for the record

`MapDesk.tsx` packed the book to its panes' natural width whenever it had measured one; where the day could not stand
beside it (1,440–1,900 px: the book took the row), the box was the row's width but the matrix stopped at its natural width
— a dead strip after CHARM · NET (1,600 px: 165 px). The book is now packed only while the day stands beside it; where the
day wraps under, the matrix's columns share the full box. The calendar view had the opposite fault: its natural width
counted 120 px a column while the grid draws at least 128, so a box packed to it cut the last greek's column (CHARM, 15 px);
`ExposureLedger.tsx` now counts the drawn floor (`CELL_DRAWN_MIN`). Terrain's rails and the Board were checked at every
width and have no dead strip.
