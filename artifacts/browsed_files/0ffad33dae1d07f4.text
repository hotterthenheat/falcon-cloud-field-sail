# UnusualWhales API

The official Unusual Whales API gives you 100+ endpoints for options flow, dark pool, congressional trading, Greek exposure, volatility, and more.

## Quick Start

**Base URL:** `https://api.unusualwhales.com`

**Authentication:** Bearer token in header
```
Authorization: Bearer YOUR_API_KEY
```

## Authentication errors

A request without a usable API token returns HTTP 401 and a `WWW-Authenticate` header carrying the `Bearer` challenge. A request whose token is restricted to other routes returns HTTP 403. Both bodies carry a `reason` field naming the specific failure. Branch on `reason`, not on `message`, whose wording can change.

| Status | `reason` | What happened |
|--------|----------|---------------|
| 401 | `missing_token` | The request carried no API token. |
| 401 | `malformed_token` | A token was supplied but is not a UUID. |
| 401 | `unrecognized_token` | The token is a UUID that no active token matches. It was revoked or regenerated, or it belongs to a different account. |
| 403 | `route_not_permitted` | The token is valid, and its route restrictions exclude this route. |

API tokens are UUIDs, such as `123e4567-e89b-12d3-a456-426614174000`. Create and manage them at https://unusualwhales.com/dashboard/api.

Every one of these responses carries `retryable: false`. Replaying the same request unchanged returns the same error. Retrying with a corrected token can succeed. Each response also carries a `request_id` matching the `x-request-id` response header. Quote it when you contact dev@unusualwhales.com.

## Machine-readable docs

The API publishes plain-text documentation for AI agents and developer tools:

- **Full Markdown index:** `GET https://api.unusualwhales.com/docs.md` returns the API overview and endpoint index as Markdown.
- **llms.txt index:** `GET https://api.unusualwhales.com/llms.txt` lists every documented API operation by tag, with a short description and a link to its Markdown reference page. It also links to the OpenAPI specification, Kafka streaming documentation, websocket documentation, the MCP server, and the agent skill file.
- **Markdown operation pages:** Append `.md` to an operation URL, such as `https://api.unusualwhales.com/docs/operations/<operation_id>.md`, to get that operation's reference as Markdown. Requests to `/docs` and operation URLs without a `text/html` `Accept` header also return Markdown.

```bash
curl https://api.unusualwhales.com/llms.txt
curl https://api.unusualwhales.com/docs.md
curl https://api.unusualwhales.com/docs/operations/PublicApi.AlertsController.alerts.md
```
