# UnusualWhales API

> The Unusual Whales API provides market data for options flow, dark pool trading, congressional trading, Greek exposure, volatility, and related datasets.

API requests use the base URL `https://api.unusualwhales.com` and require a bearer token in the `Authorization` header. Create and manage API tokens at https://unusualwhales.com/dashboard/api.

Each operation link below returns Markdown. The OpenAPI specification contains the complete machine-readable contract.
